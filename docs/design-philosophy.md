# Design Philosophy of Cricket247

## Principles

Since the app is all about cricket, every layout, visual elements, typography, and interaction should resemble the sport in some way. The design choice should be intentional, not template-driven.
Visual Hierarchy is paramount.
No unnecessary cards in cards mess.
Design choices has to feel native mobile app like, as the app is primarily used on mobile devices.

### Layout

Responsive design is crucial, for mobile and tablet views, interactive elements should be touch and gesture friendly, with larger tap targets and intuitive navigation.
Desktop view can leverage the larger screen by having asymmetrical two column layout.
Ample whitespace in text heavy pages, App like layout on interactive pages.
